This is a simple godot game where a smol lil guy flies a paper plen and you have to make sure it doesn't hit birds





https://github.com/user-attachments/assets/6e4c3537-3704-4168-9c37-0a3ebbeaf338



## Controls:
- Right Arrow -> Increase Speed
- Left Arrow -> Decrease Speed
- Up Arrow -> Ascend
- Down Arrow -> Descent
