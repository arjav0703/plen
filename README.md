# Plen 🛩️

This is a simple godot game where a smol lil guy flies a paper plen and you have to make sure it doesn't hit birds




https://github.com/user-attachments/assets/8c329163-7b93-4d30-8298-9a77c647eb71


## Controls:
- Right Arrow -> Increase Speed
- Left Arrow -> Decrease Speed
- Up Arrow -> Ascend
- Down Arrow -> Descent

## Artwork

All the art is drawn by me in aseprite.

### AI usage declaration
used ai occasionaly as i got stuck. some parts (~40%) of code are ai generated. no tutorials used.
